# Site sub2cad.fr

Site de Sub2Cad, géré avec Ohmycad. Hébergé sur GitHub Pages : chaque modification enregistrée sur la branche `main` de ce dépôt part en ligne en 1 à 2 minutes.

## Modifier le site ou publier un article avec un agent IA
Vous avez un accès en écriture à ce dépôt GitHub. Le plus simple :
1. Ouvrir un agent IA qui sait travailler sur un dépôt GitHub, par exemple Claude Code (sur https://claude.ai/code, sans rien installer, ou dans un terminal), et lui donner le dépôt `Ohmycad/site-sub2cad`.
2. Lui demander en langage courant, par exemple : « Écris un article de blog sur SOLIDWORKS PDM pour une PME de 10 personnes, publie-le. » ou « Change le numéro de téléphone du pied de page. »
3. L'agent lit le fichier `CLAUDE.md` (les règles du site), fait la modification et la publie.
4. Vérifier le résultat sur https://sub2cad.fr une ou deux minutes plus tard.

Sans agent, on peut aussi ajouter un article à la main sur github.com : dossier `src/blog/`, « Add file », en reprenant l'en-tête d'un article existant.

## Ce que fait le site pour vous
- Chaque demande envoyée par le formulaire arrive dans HubSpot et vous êtes prévenu par mail.
- Les entreprises qui visitent le site remontent dans HubSpot (Buyer Intent), pour les visiteurs qui ont accepté les cookies.
